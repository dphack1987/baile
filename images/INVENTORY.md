## 🎯 Recomendaciones

### Tamaño de Imágenes
- **Hero Banner**: 1920x1080px (mínimo)
- **Tarjetas de Servicio**: 800x600px
- **Galería**: 1200x900px
- **Instructores**: 400x400px (cuadradas)
- **Hoteles**: 1600x900px

### Formato
- Usar JPG para fotos con mucho color
- Usar PNG para imágenes con transparencia
- Comprimir imágenes para optimizar carga
- Usar WebP para mejor compresión (opcional)

### Nombres de Archivos
- Usar guiones en lugar de espacios
- Usar minúsculas
- Ser descriptivos: `salsa-class-hotel-name.jpg`

## 📝 Instrucciones para Agregar Imágenes

1. Coloque las imágenes en la carpeta correspondiente
2. Optimice el tamaño (máximo 500KB por imagen)
3. Use nombres descriptivos
4. Actualice este inventario
5. Actualice el HTML para referenciar las nuevas imágenes

## 🔗 Referencias en el Código

### HTML
- Galería: `<img src="images/portfolio/page_1.png">`
- Servicios: `<img src="images/classes/class-1.jpg">`
- Instructores: `<img src="images/instructors/instructor-1.jpg">`

### CSS
- Background images en hero section
- Imágenes de fondo en secciones especiales
